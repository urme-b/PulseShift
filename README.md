# PulseShift

**[Live Demo →](https://urme-b.github.io/PulseShift/)**

PulseShift forecasts climate-driven *suppression* of outdoor physical activity — the loss of a
planned session to heat, cold, wind, or smoke — and ranks the safest adaptation that preserves it.

The repository has two parts that share one idea:

1. **`research/` — the evidence layer.** A reproducible pipeline that builds a real dataset for
   Washington DC (2022–2024) from public sources, fits and *calibrates* a suppression-risk model,
   and evaluates a safety-constrained adaptation policy. Every figure and table in
   [`paper/paper.md`](paper/paper.md) is regenerated by two commands.
2. **The app** — an organizer-facing decision-support tool (Node) that applies the same heat-index
   and risk logic to a single planned session and recommends an adaptation.

## What the study found

On real DC data, with out-of-time (2024) validation:

- Environmental + temporal features lift suppression-forecast **AUROC from 0.66 (season-aware
  climatology) to 0.89**.
- A **balanced** logistic model is badly **over-confident** (Brier 0.136, ECE 0.249); both an
  unweighted model and **isotonic calibration** restore reliability (Brier ≈ 0.04) with discrimination
  essentially unchanged — calibration, not accuracy, is what makes the risk usable.
- Marginal exposure–response is **confounded by season** (cold dominates suppression here), but
  during the **June 2023 wildfire-smoke episode** ridership fell to **0.76× expected at AQI 196** —
  among the lowest ~8% of summer weekday days.
- A safety-constrained time-shift policy could recover **up to ~37% of otherwise-lost activity**
  (an upper bound) while never recommending an unsafe hour. Discretionary riders bear ~1.8× the
  burden of committed riders.

See [`paper/paper.md`](paper/paper.md) for the full write-up and [`research/README.md`](research/README.md)
to reproduce it.

## Reproduce the research

```bash
python3 -m venv .venv
.venv/bin/pip install -r research/requirements.txt
cd research
PYTHONPATH=. ../.venv/bin/python scripts/build_data.py     # download + build the panel
PYTHONPATH=. ../.venv/bin/python scripts/run_analysis.py   # models, figures, tables
```

Data sources: Capital Bikeshare trip history, NOAA Local Climatological Data (Reagan National),
and EPA AirData daily AQI. All public; nothing hand-edited.

## Run the app

```bash
npm install
npm run dev            # http://127.0.0.1:4173
npm test
```

PostgreSQL mode: `npm run dev:postgres` (expects a local database named `pulseshift`). The app pulls
live conditions from the NOAA National Weather Service and EPA AirNow APIs, scores a planned
session, ranks adaptations, and persists evaluations to SQLite or PostgreSQL.

## Honest scope

The app's risk score is an interpretable **heuristic** for a single session; the paper is the
empirical layer that the app previously lacked. The suppression outcome in the study is
*constructed* from ridership relative to a weather-free climatology (no public dataset labels
skipped sessions), the analysis is a single city and activity, and RAM is a model-based expected
benefit, not a measured causal effect. These are stated as limitations in the paper.
